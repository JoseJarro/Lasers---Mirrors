# Lasers & Mirrors
Es un juego de lógica y resolución de acertijos en el que el jugador debe redirigir un rayo láser mediante espejos colocados estratégicamente en el tablero. Cada nivel presenta una configuración distinta con obstáculos y objetivos, obligando al jugador a analizar el recorrido de la luz y aprovechar las leyes de reflexión para encontrar la solución correcta. A medida que se avanza, los desafíos aumentan en complejidad, requiriendo planificación y pensamiento lógico para completar cada rompecabezas.

Proyecto para la materia Paradigmas de la Prog
